🔧 Tech Stack:
• Frontend: React 19, TypeScript, Vite, Tailwind CSS, Three.js
• Backend: Node.js, Express REST API
• Database: PostgreSQL via Supabase (Connection Pooling)
• Hosting & CI/CD: Vercel (Edge CDN) + Render

💡 Key Learnings & Engineering Problem-Solving:
Throughout this project, I used modern AI-assisted engineering tools to accelerate implementation while taking full responsibility for code architecture, debugging, and deployment. Some of the most valuable lessons came from performance troubleshooting:
1. Identifying and fixing an async slug resolution bottleneck that cut direct showtime deep-link loading from 4.6 seconds down to 919 ms.
2. Refactoring sequential database queries in the Admin portal into parallel `Promise.allSettled` batches, cutting data resolution time by over 55%.
3. Managing WebGL render loops carefully so mobile touch scrolling stays responsive and fluid.

Note: CineBook V3 is a portfolio demonstration with simulated checkout (no real tickets or payments are processed).
